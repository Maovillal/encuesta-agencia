# Encuesta Agencia

Encuesta de experiencia del cliente. Este repositorio contiene **únicamente** la
página pública que abre el cliente al escanear su código QR.

No vive aquí nada del backend ni del tablero de resultados: el Apps Script, el
padrón de asesores y el tablero (que contiene teléfonos de clientes y la clave de
lectura) se quedan fuera del repositorio a propósito.

Se publica con GitHub Pages. La página se abre con `?asesor=<slug>`; sin ese
parámetro muestra un aviso pidiendo escanear el QR.
